## Важное про TCP и UDP

На референсном макете в экране №7 выбран **TCP Socket**. Основной учебный pipeline сначала реализует **UDP**, потому что это позволяет отдельно освоить асинхронный socket, event loop, `QThread`, batching и backpressure без reconnect state machine.

Сам экран №7 проектируется сразу как универсальный диалог выбора типа источника. В core-плане реально работает `UDP Socket`; `TCP Socket + reconnect/backoff` — явное расширение после основного проекта. Так макет и учебная архитектура не противоречат друг другу.
